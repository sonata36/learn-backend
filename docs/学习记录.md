## 1. 已确认的关键结论

### Spring Boot 4.0.8 与 3.x 的差异（重要）

- 本项目是 **Boot 4.0.8**，不是 3.x。Web starter 已改名：`spring-boot-starter-web` → **`spring-boot-starter-webmvc`**。
  网上的 3.x 教程让你加 `spring-boot-starter-web`，在本项目里是不存在的 artifact，照抄会找不到依赖。
- 测试 starter 也模块化了：`spring-boot-starter-*-test`（本项目 pom 里的 actuator-test / flyway-test / webmvc-test 就是这种写法）。
- **结论**：依赖名一律以本项目 pom 和官方文档为准，不要照抄 3.x 教程。

### 为什么移除 spring-boot-starter-security

- 只要 `spring-boot-starter-security` 在，Boot 就会启用默认过滤链、拦截所有接口并生成随机密码。
- 考核要求手写 Cookie / Session / Token 三套方案理解原理，过滤链会把过程遮住。
- **结论**：只用 `spring-security-crypto`（BCrypt 工具），不引入完整 Security。

### application.properties 与 application.yml

- 同目录下 `.properties` 优先级高于 `.yml`，两者共存会静默覆盖，是很隐蔽的坑。
- **结论**：只保留 `application.yml`。
